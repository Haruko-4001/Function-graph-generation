# 数学函数可视化与性质分析工具（Math Function Visualizer v3.1）

一个开箱即用的**纯前端**数学函数研究工具：不只是画图，还能对函数做**系统性的性质分析**与**带步骤的数值求解**。适合教学演示、作业验证与日常数学研究。

> 在线体验：<https://haruko-4001.github.io/Function-graph-generation/>

## ✨ 功能特性

### 绘图
| 模式 | 说明 |
| --- | --- |
| 显函数 `y = f(x)` | 支持 `;` 分隔最多 6 个函数叠加，两个函数时自动标注**交点** |
| 参数方程 | `x(t), y(t)`，自定义 t 范围 |
| 极坐标 | `r = r(θ)`，自动锁定等比例坐标 |
| 隐函数 | `f(x, y) = 0`，基于 **marching squares** 等值线提取（支持 `x^2+y^2=9` 写法） |
| 3D 曲面 | `z = f(x, y)`，带等高线投影 |

### 性质分析（自动生成报告）
- 零点（**Brent 方法**，含不变号的切触零点检测）
- 极大 / 极小值、单调区间
- 凹凸区间与拐点（二阶导数变号 + Brent 精化）
- 垂直 / 水平 / **斜渐近线**（水平渐近线近零值自动归零，`1/x` 显示 `y = 0` 而非 `1e-8`）
- 奇偶性、周期性
- **值域**：区间内采样极值，存在极点时标注 ⚠ 提示实际可能无界
- **定义域**：可求值率 + 未定义点（含极点）

> 报告基于**采样与数值迭代**，不是符号推导。面板底部会说明这一点，避免把 `≈[-16, 16]` 误读成 `1/x` 的真实值域。

### 分步讲解（v2.2 新增）

把「一张图 + 一张表」变成一段 **15~30 秒的分步讲解**，按教学顺序播放：

```
标题 → 画曲线 → 扫掠 → 零点 → 极值 → 单调区间 → 拐点 → 渐近线 → 自检总结
```

- 每一帧都是「重放前 N 个镜头」的累积状态，因此可暂停、可跳步、可重播
- 字幕贴在图像底部（像视频字幕），不遮挡坐标轴
- **每条结论都带独立复算的残差**：零点代回、极值验一阶导、拐点验二阶导、
  积分双精度交叉验证、奇偶/周期抽样比对；自检未通过的点会画成红色 ✕
- 分镜不是硬编码的动画代码，而是一份**固定动词表描述的数据**（见
  [`docs/OPTIMIZATION.md`](docs/OPTIMIZATION.md) 第 4.2 节），因此可校验、可复现、可换渲染器

三层结构（对应流水线的 03 → 04 → 05）：

| 层 | 文件 | 职责 |
|---|---|---|
| Facts | `js/facts.js` | 把分析结果升级为「带 residual / tol / ok 的断言集」 |
| Storyboard | `js/storyboard.js` | 断言集 → 分镜（动词白名单 + 5 条契约校验） |
| Player | `js/player.js` | 分镜 → Plotly 逐帧渲染 |

### 导出与分享（v3.0 新增）

| 按钮 | 产出 | 说明 |
|---|---|---|
| 导出 Python | `plot_xxx.py` | 只依赖 numpy + matplotlib；含 f(x)、标注、区间常量，以及 `verify()` 逐条复算结论 |
| 运行清单 | `manifest_xxx.json` | 输入、算法参数、结论统计、每个产物的指纹（FNV-1a），可追溯 |
| 复制链接 | URL | 把表达式、区间、模式、参数值编码进 `#`，打开即是同一个视图 |

导出的脚本会先过一道**静态检查**（导入白名单、拒绝 `eval/exec/open/os/subprocess`、括号配平、main 保护），
不通过就不允许下载。脚本导出后可在本机直接运行：

```bash
pip install numpy matplotlib
python plot_xp2_4.py      # 出图 + 打印每条结论的残差
```

### 探索与对比（v3.0 新增）

- **参数滑块**：表达式里出现 `a`、`b`、`w` 这类自由符号时，自动生成滑块并实时重绘
  （输入 `a*sin(x)` 试试）
- **多函数对比**：用 `;` 分隔两个函数后，报告会追加对比块——交点、谁在上方、最大间距、面积差 `∫(f1−f2)`
- **3D 切片分析**：3D 模式下填「切片 y = c」，曲面会高亮该切面，并对 `f(x, c)` 做完整的一维性质分析
- **术语库**：问「什么是拐点」「渐近线是什么」，助手会给出定义、本工具的计算方式与常见误区

### 圆锥曲线与学习中心（v3.1 新增）

**圆锥曲线视图**：输入 `x^2/4 + y^2/9 = 1`、`x^2/4 - y^2/9 = 1`、`y^2 = 4*x` 或一般式，
自动识别圆 / 椭圆 / 双曲线 / 抛物线，给出中心、焦点、顶点、`a/b/c`、离心率、准线、渐近线，
并在图上标出焦点与顶点；填曲线上的点可直接求切线。

**导数工具**：输入切点 `x₀`，一键给出切线与法线并叠加到图上；一键比较闭区间内的极值点与端点，
输出最大值、最小值、单调区间与候选点。

**知识地图与题型库**：8 个模块、62 个知识节点、71 个题型族（90 个子型）、60 条结论。
支持按知识点/题型/结论搜索，每张卡包含教材出处、前置知识、关键结论、条件、易错点，并可一键送入实验室验证。

**三层自测**：从题型卡自动生成「识别信号 → 通法选择 → 易错点」三类选择题，每次 10 题，
答完给出分层正确率与薄弱题型；练习统计保存在本机 `localStorage`。

**讲义导出**：节点可加入讲义，一键导出 Markdown；内容包含要点、结论、关联题型与示例表达式。

**专题工具**：圆锥曲线支持弦长/中点计算；导数工具支持零点个数参数扫描。

**书目**：按《导数的秘密》十章、《圆锥曲线的秘密》五章逐章收录完整小节清单，并把章节与方法对应到题型卡；
适合「照书复习」而不是只按知识点搜索。

**交互实验**：7 个实时演示——割线→切线、切线与法线、函数与导数符号、椭圆定义、
离心率与形状、参数扫描、面积累积。全部在浏览器内计算，可拖动参数观察变化。

> 课程数据与结论的整理依据人教 A 版、同济《高等数学》与《导数的秘密》《圆锥曲线的秘密》，
> 详见 [`docs/EDUCATION-UPGRADE.md`](docs/EDUCATION-UPGRADE.md)。所有结论都标注适用学段：
> 洛必达、泰勒等大学方法默认折叠，避免高中解答题误用。

### 智能助手（中文自然语言，附求解步骤）
```
y = x^2 - 4          → 直接绘图
导数 / 二阶导数       → 符号求导 + 数值验证
积分从 0 到 2pi      → 自适应 Simpson，含误差估计
零点 / 解方程         → 扫描 + Brent，逐步说明
x 趋近于 0 的极限     → 双侧逼近，判定是否存在
在 x=0 处 4 阶泰勒展开 → 符号导数求系数
交点                 → 两个函数叠加时自动求解
极值 / 单调性 / 凹凸 / 渐近线 / 周期 / 奇偶 / 值域 / 定义域
```

积分限支持 `3.14`、`2pi`、`pi`、`e`、负数等写法；三种句式均可：
`积分从 0 到 2pi`、`[0, 2pi]`、`0 到 2pi 的积分`。
若句中没写积分限，助手会**明确提示**已回退到当前可视区间，而不是默默算一个别的区间。

### 输入体验
- 兼容中文输入习惯：`×`、`÷`、`（）`、`π`、`√x`、`y=` 前缀自动规范化
- 输入即校验：语法错误、未知变量、范围错误均有中文提示
- 自动重绘（防抖）：连续修改时会排队执行，最后一次输入不会被丢弃
- 数值表与 **CSV 导出**：显函数、参数方程、极坐标均可导出（多函数按列展开）
- 图像 PNG 导出（Plotly 工具栏）
- 后台标签页也能算完：分块计算在页面不可见时自动改用定时器，不会卡在「正在计算」

## 🌐 部署与分享

> 「一个 HTML 文件」和「一个网址」是两件事：**文件**可以直接发给别人双击打开，
> **网址**则必须有一个静态托管服务。下面三种方式按需选择。

### 方案 A：单文件 HTML（最快，适合发给别人 / 上传任意托管）

把 `index.html + css + js` 打包成一个自包含 HTML：

```bash
npm run build            # 生成 dist/math-function-visualizer.html（约 474 KB，库走 CDN）
npm run build:offline    # 生成离线版（约 4.3 MB，完全不联网也能用）
```

产物可直接：微信/邮件发送、双击打开、丢到任意静态托管（GitHub Gist、OSS、对象存储、Netlify Drop）。
打包脚本会把应用脚本内嵌为 `<script type="text/x-app">`，加载器在库就绪后按序执行，行为与开发版完全一致。

### 方案 B：GitHub Pages（本仓库已启用，线上地址见文首）

1. 把项目推到 GitHub 仓库（`git add . && git commit && git push`）
2. 仓库页面 → **Settings → Pages**
3. Source 选 **Deploy from a branch**，Branch 选 `main`、目录选 `/ (root)`
4. 保存后约 1 分钟，得到网址：`https://<用户名>.github.io/<仓库名>/`

之后每次 `git push` 都会自动更新线上版本。

### 方案 C：拖拽式托管（无需 Git）

- **Netlify Drop**：打开 <https://app.netlify.com/drop>，把项目文件夹拖进去，即时得到 `xxx.netlify.app`
- **Vercel / Cloudflare Pages**：导入仓库或上传文件夹，同样一键得到网址

> 无论哪种方式都不需要后端：本项目是纯静态页面，只有 CDN 依赖。
> 若目标环境无法访问公网 CDN，请发布 `--offline` 版本。

## 🧮 数值方法说明

| 能力 | 算法 | 精度目标 |
| --- | --- | --- |
| 零点 | 扫描 + Brent（割线/反二次插值 + 二分兜底） | 1e-13 |
| 切触零点 | `\|f(x)\|` 局部极小 + 黄金分割精化 | 1e-7 |
| 极值 | 导数零点 + 二阶导 / 左右符号分类 + 黄金分割精化 | 1e-4 |
| 定积分 | 自适应 Simpson + Richardson 误差估计 | 1e-9 |
| 极限 | 双侧 `10^-1…10^-9` 步距逼近 | 1e-7 收敛判定 |
| 泰勒展开 | mathjs 符号逐阶求导，系数 `f⁽ᵏ⁾(a)/k!` | 精确（符号） |
| 渐近线 | 极点（`1/f` 求根）/ 无穷远极限 / 斜率-截距收敛 | 1e-3 ~ 1e-6 |
| 值域 | 区间采样极值，剔除断点邻域 | 采样精度 |

## ⚠️ 已知局限

这些是**刻意公开**的边界，避免误用：

1. **周期检测是候选表启发式**：只尝试 `π/2, π, 2π, 4π, 0.25~10` 等常见值，
   像 `0.7` 这样的非候选周期识别不出来。
2. **采样点数固定**：求根 1000 点、显函数绘图 1600 点（参数方程 2000、极坐标 2400、
   隐函数 200×200、3D 80×80）。高频振荡函数可能漏根、漏极值。
3. **结论多为数值近似**：`x≈`、`y≈`、`≈[...]` 都是这个意思；只有求导与泰勒系数是符号计算。
4. **值域不是全局值域**：只反映当前可视区间，且会剔除极点邻域，带 ⚠ 时实际可能无界。
5. **圆锥曲线只对轴对齐情形给完整性质**：含 `xy` 项的旋转曲线只能识别类型、中心、轴长与离心率，
   不提供焦点、准线、切线。
6. **自测是「方法识别」层**：题目由题型卡的识别信号/通法/易错点自动生成，不是完整的计算题库；
   涉及具体数值的大题仍需学生自行演算。
7. **书目是目录级索引**：按两本书的完整目录收录章节与小节，并映射到题型卡，但不复制原书正文、例题与答案。
   目前只有第二章有精讲样章，其余章节是索引级。
8. **圆锥定点定值与极值点偏移暂无交互实验**：7 个基础教学实验（割线→切线、椭圆定义、离心率、面积累积等）已上线，但这两个专题仍以结论卡与数值工具为主。
9. **大学方法单独标记**：洛必达、泰勒、中值定理只作为结论卡出现，不进入高中解题步骤推荐。
10. **未做性能压测**：本项目没有 benchmark，只有界面右下角的 FPS / 上次绘图耗时。

对外提供 4 个工具：`analyze_function`（性质 + 逐条残差）、`build_storyboard`（分镜 JSON）、
`export_python`（可运行脚本）、`export_manifest`（运行清单）。协议冒烟：`npm run mcp:smoke`。
