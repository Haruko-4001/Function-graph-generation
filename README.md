# 数学函数可视化与性质分析工具（Math Function Visualizer v2.0）

一个开箱即用的**纯前端**数学函数研究工具：不只是画图，还能对函数做**系统性的性质分析**与**带步骤的数值求解**。适合教学演示、作业验证与日常数学研究。

## ✨ 功能特性

### 绘图
| 模式 | 说明 |
| --- | --- |
| 显函数 `y = f(x)` | 支持 `;` 分隔最多 6 个函数叠加，两个函数时自动标注**交点** |
| 参数方程 | `x(t), y(t)`，自定义 t 范围 |
| 极坐标 | `r = r(θ)`，自动锁定等比例坐标 |
| 隐函数 | `f(x, y) = 0`，基于 **marching squares** 等值线提取（支持 `x^2+y^2=9` 写法） |
| 3D 曲面 | `z = f(x, y)`，带等高线投影 |

### 性质分析（自动生成报告）
- 零点（**Brent 方法**，含不变号的切触零点检测）
- 极大 / 极小值、单调区间
- 凹凸区间与拐点（二阶导数变号 + 二分精化）
- 垂直 / 水平 / **斜渐近线**
- 奇偶性、周期性、值域、定义域（未定义点检测）

### 智能助手（中文自然语言，附求解步骤）
```
y = x^2 - 4        → 直接绘图
导数 / 二阶导数     → 符号求导 + 数值验证
积分从 0 到 3.14   → 自适应 Simpson，含误差估计
零点 / 解方程       → 扫描 + Brent，逐步说明
x 趋近于 0 的极限   → 双侧逼近，判定是否存在
在 x=0 处 4 阶泰勒展开 → 符号导数求系数
交点               → 两个函数叠加时自动求解
极值 / 单调性 / 凹凸 / 渐近线 / 周期 / 奇偶 / 值域 / 定义域
```

### 输入体验
- 兼容中文输入习惯：`×`、`÷`、`（）`、`π`、`√x`、`y=` 前缀自动规范化
- 输入即校验：语法错误、未知变量、范围错误均有中文提示
- 自动重绘（防抖）、数值表生成、**CSV 导出**、图像 PNG 导出（Plotly 工具栏）

## 🧮 数值方法说明

| 能力 | 算法 | 精度目标 |
| --- | --- | --- |
| 零点 | 扫描 + Brent（割线/反二次插值 + 二分兜底） | 1e-13 |
| 切触零点 | `\|f(x)\|` 局部极小 + 黄金分割精化 | 1e-7 |
| 极值 | 导数零点 + 二阶导 / 左右符号分类 + 黄金分割精化 | 1e-4 |
| 定积分 | 自适应 Simpson + Richardson 误差估计 | 1e-9 |
| 极限 | 双侧 `10^-1…10^-9` 步距逼近 | 1e-7 收敛判定 |
| 泰勒展开 | mathjs 符号逐阶求导，系数 `f⁽ᵏ⁾(a)/k!` | 精确（符号） |
| 渐近线 | 极点（`1/f` 求根）/ 无穷远极限 / 斜率-截距收敛 | 1e-3 ~ 1e-6 |
