# 示例函数集

按研究主题组织的推荐输入，可直接复制到输入框。

## 基础绘图

| 表达式 | 看点 |
| --- | --- |
| `sin(x)` | 周期 2π、零点 kπ、奇函数 |
| `x^2 - 4` | 零点 ±2、极小值 (0,-4)、偶函数 |
| `tan(x)` | 垂直渐近线 x = π/2 + kπ |
| `1/(x^2 + 1)` | 水平渐近线 y = 0、偶函数 |
| `exp(-x^2/4) * cos(3*x)` | 阻尼振荡、包络 |
| `log(x)/x` | 定义域 x>0、极大值 (e, 1/e) |

## 多函数叠加与交点

```
x^2 ; 2*x          → 交点 (0,0) 与 (2,4)
sin(x) ; x/2       → 三角与线性的交点
x^3 - 3*x ; x      → 三次曲线与直线
```

## 渐近线研究

```
1/x                → 垂直 x=0，水平 y=0
(2*x + 1)/(x - 1)  → 垂直 x=1，水平 y=2
x + 1/x            → 斜渐近线 y = x，垂直 x=0
(x^2 + 1)/x        → 斜渐近线 y = x
```

## 参数方程

| x(t) | y(t) | 曲线 |
| --- | --- | --- |
| `3*cos(t)` | `2*sin(t)` | 椭圆 |
| `t*cos(t)/10` | `t*sin(t)/10` | 阿基米德螺线 |
| `cos(t)^3` | `sin(t)^3` | 星形线 |
| `16*sin(t)^3` | `13*cos(t)-5*cos(2*t)-2*cos(3*t)-cos(4*t)` | 心形曲线 |

## 极坐标

| r(θ) | 曲线 |
| --- | --- |
| `1 - cos(theta)` | 心形线 |
| `sin(3*theta)` | 三叶玫瑰线 |
| `cos(2*theta)` | 四叶玫瑰线 |
| `theta/5` | 阿基米德螺线 |

## 隐函数

| 表达式 | 曲线 |
| --- | --- |
| `x^2 + y^2 - 9` | 圆（也可写 `x^2 + y^2 = 9`） |
| `x^3 + y^3 - 3*x*y` | 笛卡尔叶形线 |
| `(x^2 + y^2)^2 - 8*(x^2 - y^2)` | 双纽线 |
| `y^2 - x^3 + 2*x` | 椭圆曲线 |

## 3D 曲面

| 表达式 | 看点 |
| --- | --- |
| `sin(sqrt(x^2 + y^2))` | 涟漪 |
| `sin(x) * cos(y)` | 波浪网格 |
| `(x^2 - y^2)/10` | 马鞍面 |
| `1/(1 + x^2 + y^2)` | 钟形曲面 |

## 微积分练习（配合助手提问）

| 表达式 | 推荐提问 |
| --- | --- |
| `sin(x)` | `积分从 0 到 3.14`（结果 ≈ 2） |
| `1/(1 + x^2)` | `积分从 0 到 1`（结果 ≈ π/4） |
| `sin(x)/x` | `x 趋近于 0 的极限`（= 1） |
| `(1 + 1/x)^x` | `x->无穷 的极限`（= e） |
| `e^x` | `在 x=0 处 5 阶泰勒展开` |
| `x^3 - 6*x^2 + 11*x - 6` | `零点`（1、2、3） |
