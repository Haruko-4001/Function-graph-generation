# 面向教材与题型的函数学习能力升级方案

> 版本：v4.0 规划稿　|　基线：v3.0（提交 `124168e`）
> 目标：把现有「函数分析器」升级为「函数课程学习与解题工作台」，让学生从**看懂一条曲线**走到**掌握一类题型**。
> 依据：人教 A 版（2019）高中数学、同济大学《高等数学》第七版、《导数的秘密（第二版）》《圆锥曲线的秘密》。

---

## 0. 结论摘要

现有项目在**数值分析**这一层已经比较扎实：零点、极值、单调、凹凸、拐点、渐近线、奇偶、周期、值域、定义域，以及残差自检、分步讲解、参数滑块、多函数对比、3D 切片、脚本导出，都是可复用的底座。

但把它放到真实学习场景里，仍有三个结构性缺口：

1. **没有课程结构**：所有能力平铺在一个页面里，学生不知道「先学什么、这一节对应哪道题」。
2. **没有题型层**：工具能算出「有几个零点」，却不能告诉学生「这是零点个数问题，通法是分离参数，易错点是端点取不取」。
3. **圆锥曲线完全缺位**：目前只能用隐函数画出椭圆/双曲线，无法给出焦点、离心率、准线、渐近线、弦长、中点弦、切线这些解题真正需要的量。

因此本方案提出三个转变：

| 从 | 到 |
| --- | --- |
| 函数分析器 | 课程学习工作台 |
| 一个计算结果 | 一张知识卡 + 一类题型卡 + 一次可复现实验 |
| 只回答「是多少」 | 回答「怎么识别、怎么下手、为什么成立、容易错在哪」 |

首版目标量化：

- **8 个一级模块、62 个知识节点、90 个题型模板、约 180 条结论与易错点**
- 其中 **32 个题型**做到「可交互复现 + 分步解答」，其余先做内容卡
- 教材例题回归验证不少于 **60 道**
- 新增内容不破坏现有离线单文件能力

### 1.2 覆盖范围

**纳入**

- 高中函数主线：函数概念与表示 → 函数性质 → 基本初等函数 → 导数概念与运算 → 导数应用
- 高中解析几何中的圆锥曲线：定义、方程、几何性质、直线与圆锥曲线、定点定值最值
- 大学一年级：函数与极限、连续、导数与微分、中值定理、泰勒公式、单调凹凸极值、不定积分与定积分基础
- 与上述内容直接相关的参数方程、极坐标

**不纳入（首版）**

- 数列、概率统计、立体几何、空间向量等独立章节（只在题目需要时作为工具引用）
- 微分方程、多元微积分、级数、复变函数
- 竞赛专属的超纲技巧；大学方法（洛必达、泰勒、拉格朗日中值定理）单独标注，不与高中解法混排

### 1.3 一个必须坚持的原则

> **每条结论都要标明适用范围。**

同一个结论在高中和大学里的「可用性」不同。例如洛必达法则、泰勒展开在高中解答题中通常不能直接作为得分依据。内容模型必须携带 `examUse` 字段：

| 标记 | 含义 | 呈现方式 |
| --- | --- | --- |
| `highschool` | 高中教材内，可直接使用 | 默认显示 |
| `extension` | 高中拓展，需说明或另证 | 折叠显示，标注「拓展」 |
| `university` | 大学方法，高中考试慎用 | 折叠显示，标注「大学方法，高中需另证」 |
| `caution` | 常见误用结论 | 红色警示，必须给反例 |

### 4.1 A 函数概念与表示（10 型）

| 题型族 | 子型 | 识别信号 | 通法 / 关键结论 | 现有功能 |
| --- | --- | --- | --- | --- |
| A-1 求定义域 | 分式、偶次根、对数、正切、复合、实际背景 | 出现分母/根号/对数/ tan | 列限制 → 求交集 → 写成区间；**定义域优先**，先定域再化简 | ◐ C3 只给采样比例 |
| A-2 求解析式 | 待定系数、换元、方程组、奇偶性补全 | 已知函数类型或 f(g(x)) | 设式 → 代条件 → 解方程；换元后注意新变量范围 | ✗ |
| A-3 求值域 | 单调性、配方法、换元、分离常数、判别式、基本不等式、导数、数形结合 | 问「取值范围」且无参数 | 先看单调，再选代数变形；分式优先分离常数，根式优先换元 | ◐ C3 采样值域 |
| A-4 图像变换 | 平移、伸缩、对称、翻折、复合 | 给出 f(x) 与变换 | 对 x 的变换「反着来」；`y=f(\|x\|)` 保留右侧再对称 | ✗ |
| A-5 分段函数 | 求值、图像、方程、不等式 | 出现 `{` 或绝对值 | 分段讨论，端点单独验；图像看接头 | ○ C1 |
| A-6 抽象函数 | 赋值、单调、奇偶、周期 | 只给 f(x+y)=… 无解析式 | 赋 0、赋 −x、赋 x=y；先证奇偶再证单调 | ✗ |

**核心结论**

- 定义域是「先决条件」：化简可能扩大定义域，最后必须回到原式检验。
- 值域的八种通法要按「结构」选，不按「喜好」选：分式看常数分离，二次看配方，根式看换元，含参看判别式或导数。
- 图像变换口诀：**加左减右、加下减上；对 x 伸缩取倒数**。

### 4.2 B 函数性质（12 型）

| 题型族 | 子型 | 识别信号 | 通法 / 关键结论 | 现有功能 |
| --- | --- | --- | --- | --- |
| B-1 单调性判断/证明 | 图像法、定义法、导数法、复合函数 | 问「在区间上单调」 | 定义法作差因式分解；导数法看符号；复合「同增异减」 | ✅ C3 数值区间 |
| B-2 奇偶性 | 判断、求参数、补全图像 | 出现 f(−x) | 先看定义域是否对称；`f(−x)=±f(x)` | ✅ C3 |
| B-3 周期性 | 求周期、用周期求值 | f(x+T)=f(x) | 常见：`f(x+a)=−f(x)` ⇒ T=2a；`f(x+a)=1/f(x)` ⇒ T=2a | ◐ C3 候选表 |
| B-4 对称性 | 轴对称、中心对称、两个对称推出周期 | f(a+x)=f(a−x) 等 | 轴对称 x=a；中心对称 (a,b)；两条对称轴间距为半周期 | ✗ |
| B-5 零点与方程 | 零点存在性、零点个数、方程根 | 问「有解/有几个解」 | 零点定理 + 单调性；个数问题转图像交点 | ✅ C4/C3 |
| B-6 凹凸与拐点 | 判断、拐点、凹凸区间 | 出现 f'' 或图像弯曲 | f''>0 凹向上；f'' 变号才是拐点 | ✅ C3（需标注大学/拓展） |
| B-7 图像与性质综合 | 读图、识图、选图 | 给图像选解析式 | 先看定义域/奇偶，再看特殊点/渐近线 | ◐ C1+C3 |

**核心结论**

- 奇偶性三前提：定义域对称、f(−x) 有意义、恒等关系成立。
- 对称轴与周期：若 f 有两条对称轴 x=a、x=b，则 T=2|a−b|；若有一个对称轴和一个对称中心，则 T=4|a−b|。
- 零点存在定理只保证「存在」，不保证「唯一」；唯一性必须另加单调性。

| E-8 不等式证明 | 构造函数、放缩、切线不等式、数列不等式 | 「证明 f(x)≥g(x)」 | 移项构造 h=f−g，证 h_min≥0；常用 `e^x≥x+1`、`ln x≤x−1` | ✗ |
| E-9 极值点偏移 | 单变量、双变量、拐点偏移 | 给 `f(x1)=f(x2)` 比较 x1+x2 | 构造 `F(x)=f(x)−f(2x0−x)`，判单调与符号 | ✗ |
| E-10 双变量 | 任意/存在、主元转换、消元 | 两个变量 x1,x2 | 固定一个看作参数；齐次化；主元法 | ✗ |
| E-11 参数讨论 | 分类讨论、整数最值、必要探路 | 问「求 a 的取值范围/整数 a」 | 先必要条件缩小范围，再验证充分性 | ◐ C8 |
| E-12 综合 | 实际优化、构造函数比大小、估值、三次函数 | 应用题/比较大小 | 建模 → 求导 → 验端点；三次函数看判别式与对称中心 | ✗ |

**核心结论（E 模块必须内置）**

1. **切线**：在某点 `y=f(x0)+f'(x0)(x−x0)`；过点必须先设切点，不能直接把点当切点。
2. **单调**：`f'>0` ⇒ 严格增；`f'≥0` 且零点离散 ⇒ 仍严格增。讨论含参时按「导数根是否存在、根是否在区间内、根的大小」三层分类。
3. **极值**：`f'=0` 只是候选；必须验左右符号或二阶导。`f''=0` 不是拐点的充分条件。
4. **恒成立**：`∀x∈D, f(x)≥m ⇔ min f≥m`；`∃x∈D, f(x)≥m ⇔ max f≥m`。量词与最值类型必须一一对应。
5. **零点个数**：优先分离参数，把「f(x)=0 有几个根」变成「y=a 与 y=g(x) 有几个交点」；分离后必须检查 g 的单调性与渐近行为。
6. **常用放缩**（条件！）：`e^x≥x+1`（x∈R，x=0 取等）；`ln x≤x−1`（x>0）；`ln x≥1−1/x`（x>0）；`sin x<x`（x>0）。
7. **极值点偏移**：对称构造是通法；比较 `x1+x2` 与 `2x0` 本质是比较 `f(x1)` 与 `f(2x0−x1)`。
8. **三次函数**：`f'=3ax²+2bx+c`；最多两个极值点、三个零点；图像关于 `x=−b/(3a)` 中心对称。

- 双曲线 `x²/a²−y²/b²=1`：`c²=a²+b²`，`e=c/a>1`，渐近线 `y=±(b/a)x`。
- 抛物线 `y²=2px`：焦点 `(p/2,0)`，准线 `x=−p/2`，焦半径 `x0+p/2`。
- 点差法：椭圆中点弦 `k_AB·k_OM=−b²/a²=e²−1`；双曲线 `k_AB·k_OM=b²/a²=e²−1`。使用前必须确认弦存在、中点不是中心。
- 焦点三角形：椭圆 `S=b²tan(θ/2)`；双曲线 `S=b²cot(θ/2)`（θ 为顶角）。
- 切线：椭圆 `xx0/a²+yy0/b²=1`；双曲线 `xx0/a²−yy0/b²=1`；抛物线 `yy0=p(x+x0)`。
- 阿基米德三角形：抛物线两条切线交于 P，若 P 在准线上，则两切线垂直且切点弦过焦点。

### 4.8 H 参数方程与极坐标（4 型）

| 题型族 | 子型 | 识别信号 | 通法 / 关键结论 | 现有功能 |
| --- | --- | --- | --- | --- |
| H-1 参数化 | 圆、椭圆、直线参数 | 求最值/范围 | 圆 `(a+r cosθ,b+r sinθ)`；椭圆 `(a cosθ,b sinθ)` | ◐ C1 |
| H-2 极坐标 | 极坐标方程、ρ 的几何意义 | 出现 ρ、θ | `x=ρcosθ, y=ρsinθ` | ◐ C1 |
| H-3 互化 | 参数↔普通、极坐标↔直角 | 要求化普通方程 | 消参；平方关系 | ✗ |
| H-4 统一方程 | 圆锥曲线统一形式 | 涉及焦点-准线 | `ρ=ep/(1−e cosθ)`（拓展） | ✗ |

- **结论/公式**：带条件
- **例题**：题干 + 分步解答 + 图像
- **变式**：改一个条件，答案如何变

- **一键实验**：把例题参数带入现有绘图/求导/自检

- 首版公式用 Unicode + HTML 上下标（`x²/a² + y²/b² = 1`），保证离线与性能

- 数学符号统一：`f′(x)`、`Δx`、`⇔`、`∀`、`∃`；中文与公式之间留细空格
- 图像配色沿用现有薄荷绿/琥珀/紫罗兰语义：函数=薄荷，导数=琥珀，辅助线=灰，错误=红

### 7.6 两个可落地的题型卡样例

**样例一：过点切线（E-4 族）**

| 字段 | 内容 |
| --- | --- |
| 识别信号 | 出现「过点 P 作切线」而不是「在点 P 处的切线」 |
| 关键区别 | 「在点」P 就是切点；「过点」P 不一定是切点，必须设切点 `(t,f(t))` |
| 通法 | 设切点 → 写切线 → 代入 P → 解出 t → 回代写方程 |
| 结论 | 切线 `y−f(t)=f'(t)(x−t)`；过 `(a,b)` 时解 `b−f(t)=f'(t)(a−t)` |
| 易错 | 把 P 当切点；漏掉「过点可作多条切线」；忘记检验 t 是否在定义域 |
| 演示 | `f(x)=x³−3x`，过 `(2,2)`；实验室自动画出切线与切点，并报告解的个数 |
| 验收 | 解的个数与图像一致；切线在切点处残差 `<1e−6` |

**样例二：椭圆焦点三角形（G-7 族）**

| 字段 | 内容 |
| --- | --- |
| 识别信号 | 椭圆上一点 P 与两焦点 F₁、F₂ 构成三角形，问面积/周长/角 |
| 通法 | 定义 `\|PF₁\|+\|PF₂\|=2a` → 余弦定理 → 面积公式 |
| 结论 | 记 `∠F₁PF₂=θ`，则 `S=b²tan(θ/2)`；周长 `2a+2c` |
| 易错 | 把 θ 当成离心率角；忘记 P 在椭圆上（定义优先） |
| 演示 | 参数化 P 点，实时显示 `\|PF₁\|`、`\|PF₂\|`、θ、S，验证三者为定值关系 |
| 验收 | 拖动 P 时 `\|PF₁\|+\|PF₂\|` 恒为 2a（误差 `<1e−9`）；面积公式与坐标计算结果一致 |

### 13.2 与方案的差异

- **题型规模**：方案写「首版 40 卡、最终 90 卡」，实际一次交付 **71 族覆盖 90 子型**，卡片数量按族计算。

- **交互实验**：方案 M7 的 7 个教学场景已落地为学习中心「实验」页签——割线→切线、切线与法线、
  函数与导数符号、椭圆定义、离心率与形状、参数扫描、面积累积；均为浏览器内实时计算。
- **定点定值 / 极值点偏移**：目前是结论卡 + 题型卡 + 数值工具，没有专门的动画实验室。
- **导数进阶**：零点个数参数扫描已实现；恒成立/存在性的自动求解器、极值点偏移专用实验尚未实现，
  仍以题型卡与结论卡引导学生手工完成。
